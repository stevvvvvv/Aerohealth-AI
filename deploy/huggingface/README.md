# AeroHealth AI — live demo

Engine health monitoring on the NASA C-MAPSS FD001 test fleet: Remaining Useful Life forecast with
conformal 90 % intervals, anomaly detection, SHAP explanations and risk-based alerts.

Source code, method and results: https://github.com/stevvvvvv/Aerohealth-AI

The fleet resets to its initial state whenever the Space restarts.
